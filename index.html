🤔 What is gitVisualise?

Have you ever opened a GitHub repository and felt completely lost? You see files and folders, but you have no idea how they connect or what they do. That's where gitVisualise comes in.

Think of it as a tour guide for code. You simply paste a GitHub link into gitVisualise, and it creates a beautiful, interactive map of the entire project. It shows you how the different parts connect, what each file does, and even narrates the journey for you. It's like having an experienced developer walk you through the codebase, step by step.

Whether you're a student trying to understand open-source projects, a manager wanting to see what your team is building, or a curious learner, gitVisualise makes code accessible to everyone.
